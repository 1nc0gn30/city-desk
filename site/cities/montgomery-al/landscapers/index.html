The work

Weekly route

Mowing, edging, and blowing on a set day. The visit is the same shape each week unless you change it in writing.

Cleanup

Leaves, overgrowth, and beds that need a single reset. The list of tasks is agreed before the crew arrives.

Planting

Plants are a separate visit from mowing, with the varieties and the count written down.
